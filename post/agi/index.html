从语言模型到自我模型：AGI 可能长什么样

这篇文章是我近几个月围绕"AGI 可能从哪里来"这个问题做的一轮梳理。它不是综述论文，更像是一个研究者的思考笔记——把散落在不同领域里的线索串起来，看看能拼出什么。

核心想法只有一句：AGI 很可能不是某个模型变大之后自然冒出来的，而是一套层级系统逐步闭合之后的产物。

这里说的"闭合"有个精确含义：不是系统里多了一个自我模型，而是这个自我模型的输出开始反过来修改系统本身的结构。单向堆叠再多层也不会产生什么新东西，只有形成闭环，高层的输出改写了底层的前提，才可能出现真正的主体性。

语言模型已经比我们以为的更"懂"一些东西了

语言模型的训练目标简单到近乎粗暴：预测下一个 token。可一旦规模足够大，模型就被迫吸收人类知识的统计结构——因为数学、物理、历史、法律、编程和哲学本来就被写进了语言里。

几项研究让这件事变得具体了。

Olsson 等人发现 Transformer 内部会出现专门做模式补全的注意力头（induction heads），它们的出现和 in-context learning 能力的跃迁同步发生 [1]。更惊人的是 Othello-GPT 的结果：在一个纯序列任务上训练的小模型，内部激活居然能还原出完整的棋盘状态——尽管训练目标从未要求它这样做 [2]。Yang 等人后来确认这个现象跨七种架构都能复现 [2]。Anthropic 的 mechanistic interpretability 工作则不断证明，预训练模型内部不是铁板一块，而是存在可分解的功能特征和回路 [3]。

这些证据指向一个结论：语言模型不只是在"记住句子"，它们在内部压缩出了某种弱世界结构。

但"弱"这个字很重要。语言模型主要从文本学习，不是从真实环境交互中学习。这是符号接地问题的老面孔：符号的意义不能仅从符号之间的关系中获得，还需要和外部世界的锚定 [9]。它们对物理世界、长时程行动、反事实推理仍然不稳定。能给出像样的解释，不等于拥有机制层面的世界理解。

所以语言模型更像是世界模型的雏形，而不是世界模型本身。

世界模型：从预测词到预测状态

世界模型要回答的问题比语言模型更根本：如果我做了某个动作，环境接下来会怎样变化？

这条路线不是新概念。Ha 和 Schmidhuber 早在 2018 年就把环境压缩到潜空间里做想象和规划 [4]。MuZero 更进一步，证明模型不必重建完整观测，只要学到对规划有用的表示就够了——它在围棋、象棋和 Atari 上都达到了超人水平 [5]。

最近几年最有意思的进展来自 LeCun 一路。I-JEPA、V-JEPA、V-JEPA 2 都在强调同一件事：与其生成像素，不如在抽象表示空间里预测；与其重建世界，不如学"对行动有用的世界结构" [6][12][13]。LeCun 2026 年初离开 Meta 创办 AMI Labs，拿了超过 10 亿美元种子轮，专门押注这条路线。

这条线和 LLM 路线的分歧很根本：语言是世界的充分编码吗？LeCun 说不是——语言是低带宽的二手描述，人类通过交互学到了直觉物理，光读文本不够。另一派认为语言的统计结构已经隐含了足够多的世界结构。两边目前都没有被证伪。

因果模型：从"会发生什么"到"为什么会发生"

统计相关只能告诉你两个变量经常一起出现。因果模型要告诉你的事更难：改变一个变量，会不会改变另一个变量。

Pearl 把因果推理分成了三层 [7][8]。第一层是观察——看到 X，Y 会怎样。第二层是干预——如果我做 X，Y 会怎样。第三层是反事实——如果当时没做 X，Y 本来会怎样。这三层不是一回事。当前大部分 ML 系统停留在第一层，通用智能需要第二层，科学解释和自我修正离不开第三层。

Pearl 对 LLM 的批评很直接：这些系统本质上还是在做条件概率估计，训练目标始终是 P(y|x)，不管函数类多复杂。do(x) 不是任何条件概率的变形，它的信息不可能从观测数据中凭空产生 [7][8]。

不过反方也有道理。Schölkopf 等人提出因果表征学习的可能性——如果训练数据由因果过程生成，模型的内部表征可能隐式编码了因果结构 [9]。2024-2025 年的 CausalEval 基准测试显示，前沿模型在关联层表现好，干预层尚可，反事实层差——和 Pearl 的预测一致。

我个人觉得因果模型是整个拼图里最"实"的一块。它不是猜想，而是有完整的数学框架（do-calculus，完备性定理已经证明了），问题只在于工程落地。

自我模型：系统开始把自己纳入世界

自我模型不是灵魂的同义词，也不是意识的充分条件。它更像一个智能体对自身状态的内部表征：我在哪，我能做什么，我知道什么，我不知道什么，我为什么会失败。

机器人领域早就有实证了。Bongard 等人 2006 年就展示了连续自建模——机器人通过建立自身动力学模型来提升适应能力 [10]。后续工作把视觉、自我运动和形态建模结合起来 [11][14]。这不是哲学玄学，是可测、可优化的工程对象。

LLM 里的证据更有意思。Kadavath 等人发现模型在合适设置下能较好地估计自己知道什么 [15]。Anthropic 的 Scaling Monosemanticity 工作用稀疏自编码器从 Claude 的激活中提取可解释特征，每个 token 约分解为 300 个独立概念特征 [3]。更进一步的概念注入实验表明，把特定激活向量注入模型残差流后，模型能检测到扰动并识别注入的概念——假阳性率为零，但真阳性率中等，且对分布偏移敏感 [17]。

Model(Self) 不完全是哲学比喻。有人在用激活向量这种物理手段去戳它、测它。结果远谈不上稳定，但也不是空的。

元认知的缺口

元认知——知道自己知道什么、不知道什么——是当前系统最明显的短板。

Kadavath 等人的结果说明模型能估计自身知识边界 [15]。Self-Refine 显示模型能把输出当反馈来迭代改写 [16]。但这里有个很大的空隙：会自我评分，不等于会正确地修改自身。前者是校准，后者才是认知控制。

而且幻觉问题暴露了一个根本不对称：模型能对回答产生校准的置信度，但不能可靠地评估自己生成的输出是否真实。这说明元认知机制是浅嵌入在预测过程中的，不是一套独立的监控系统。

如果元认知稳定了，就会逼出更深的问题：为什么我会把这道题判断成会？我的评估机制有没有系统偏差？这时候系统不只是在看世界，而是在看自己看世界的方式。

递归：堆叠和闭合是两回事

这里是我认为整个讨论中最需要辨析的地方。

写成符号，递归自我建模是 M(M(S))——把"我如何看待我自己"也纳入建模对象。很多高级能力和这有关：自省、纠错、创造性重构、对自身限制的重新判断。

但递归有两种完全不同的形态。

堆叠式递归（我叫它 type A）：系统建立自我模型 M₁，再建立关于 M₁ 的模型 M₂，如此向上叠加。每一层都在俯视前一层，但没有一层回头修改底层。这是一条单向的塔。可以无限延伸，却什么新性质都不会产生。像乌龟驮乌龟，驮再多也只是更长的塔。

闭合式递归（type B）：系统建立自我模型 M₁，而 M₁ 的输出反过来修改系统本身的结构。高层的表征变成了底层的因果输入，因果图中出现了一个环路。这才是 Hofstadter 说的"奇异循环"——不是无限嵌套，而是闭合 [23]。

当前绝大多数"自我改进"系统属于 type A。模型可以改写输出，但不改写自己的目标结构；可以修正答案，但不真正改变能力边界。从 type A 到 type B 的跃迁，才是真正的断层线。

闭合属性：一个判据

如果要把前面的讨论收束成一个可检验的条件，可以这样定义：

一个系统具备闭合属性，当且仅当：

  1. 系统包含对自身的内部表征（自我模型）。
  2. 该表征的输出能够因果地影响系统本身的结构或运作。
  3. 这种影响不是外部强加的训练信号，而是系统自身建模过程的产物。

条件 1 在当前 LLM 中已有弱实现。条件 2 几乎完全缺失。条件 3 区分了"人类设计的反馈环"和"系统自发形成的闭环"——前者是工程，后者才是涌现。

三个条件说的是同一件事：系统把自己的输出变成了自己的输入，形成不可拆解的环路。

哥德尔的幽灵

闭合环路上的自改进有一个绕不过去的限制。

哥德尔第一不完备定理说：任何一致的、足以表达初等算术的形式系统，都包含真但不可证明的命题 [24]。推论到自修改系统：一个系统在修改自身之后，无法从内部完全验证修改的正确性，因为验证器本身也在被修改。这不是硬件不够强就能绕过的问题，是逻辑结构的内在边界。

Schmidhuber 的 Gödel Machine 是面对这一限制的一种设计：只在能给出形式证明时才执行自修改，在可证明范围内最优，但可能错过真实但不可证明的改进 [25]。完备性和可靠性之间的权衡，任何自修改系统都必须面对。

所以闭合环路上的自改进注定是部分的、有盲区的。系统总有一些关于自己的真命题是从内部无法验证的。这不是缺陷，是递归自指的数学必然。

自由能原理：一个可选的视角

Friston 的自由能原理（FEP）把智能看作持续最小化预测误差的过程 [18][19]。它提供了一个漂亮的统一直觉：智能体不是被动反应世界，而是在持续预测、修正和自证其存在。

期望自由能的分解里有一项特别值得注意：认知价值（epistemic value），驱动系统去探索减少自身不确定性的观测。这可能和闭合属性有深层联系——系统探索自身状态的不确定性，本身就是闭合环路的内生驱动力。

但 FEP 仍然是有争议的框架。Gershman 指出它和贝叶斯脑假说的可检验预测不完全相同 [20]。Millidge 等人明确把它描述为重要但有争议的理论 [21]。Aguilera 等人分析了导出 FEP 所需的物理假设，发现适用范围比宣称的窄 [22]。FEP 适合当启发式框架，不适合当封口定理。

经验包：比 LoRA 更重的东西

如果未来世界模型能模块化，经验包可能不只是权重。它可能是表示、策略、记忆和经验更新规则的组合——比今天的 LoRA 更像"可持续更新的能力片段"。

这个方向目前更多是推测，但它指向一个有意思的可能性：经验本身变成可交易的数字资产。不是代码，不是模型权重，而是经过现实验证的因果结构和决策模式。

最后说几句

回头看这轮梳理，我比较有信心的判断有这么几条：

语言模型已经显示出弱世界模型迹象，但主要是文本智能。世界模型是从文本走向现实智能的关键一步。因果模型补上干预和反事实层，从预测走向理解。自我模型和元认知让系统开始把自己纳入可建模对象。递归自我建模可能是 AGI 的临界条件之一，但关键是闭合——自我模型的输出获得对系统结构的因果效力。自修改系统面临 Gödelian 极限，闭合环路上的自改进注定带有不完备性。

AGI 更像是多种模型在闭合条件下涌现出来的系统状态，而不是某个单一模型的自然延长。

如果把这条路画成一张图，箭头从语言模型指向世界模型，再指向因果模型、自我模型、递归自我建模，最后指向 AGI。但真正重要的也许不是箭头本身，而是系统开始把自己放进箭头里。

一旦模型开始研究"我如何预测、我如何行动、我如何改变我自己"，它就不再只是输出装置，而更像一个正在形成中的主体。

但闭合注定是不完全的。哥德尔告诉我们，任何足够强大的系统都无法完全看清自己。这个主体永远带着盲区——不是因为不够聪明，而是因为递归自指在逻辑上就是不透明的。

也许 AGI 的标志不是全知全能的自我透明，而是一个系统在带着不完全的自我理解的前提下，仍然能稳定地运转、学习和改进。
